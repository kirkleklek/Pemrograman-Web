I01–I18 adalah 18 kasus PHPUnit tersendiri (dataset dua arah/empat aktor). I19 mengacu ke 14 kasus data provider yang dicantumkan satu per satu di JUnit, I20 ke salah satu request dalam tes regresi. Jumlah baris matriks bukan jumlah keseluruhan tes.

Submission mahasiswa tidak memiliki endpoint update/delete. Hak mutasi mahasiswa diuji terhadap endpoint pengelolaan materi/tugas/nilai yang tersedia. Materi/tugas shared boleh dibaca oleh anggota kelas; hanya jawaban dan notifikasi yang privat bagi mahasiswa. Pengampu kelas, bukan semata-mata `created_by`/`uploaded_by`, menentukan hak dosen. Detail submission pribadi diuji melalui web karena API hanya menyediakan list dosen dan create mahasiswa.

Tidak ada baris FAIL/BLOCKED pada matriks otomatis ini. Infrastruktur database/seeder demo telah terverifikasi; presentasi browser/API live dicatat READY FOR UTS DEMO / PENDING PRESENTATION secara terpisah di [test-results.md](test-results.md).

## Resolusi temuan dan metrik terbaru

Status teknis M01, L01, L02, L03: **CLOSED / PASS**. Pada run terbaru: 72 tes baru / 2774 assertion; regresi Week 6 86 / 689; full suite 236 / 3686. Semuanya exit 0, tanpa failure/error/skip. Khusus IDOR I01–I18: 18 dataset / 2376 assertion. Log dan manifest tiap run ditautkan di [test-results.md](test-results.md).

- M01: pemeriksaan non-leak memakai JSON yang didekode, mencakup seluruh key dan nilai string bersarang; penolakan API 403 juga diperiksa sesuai exact error contract. Respons HTML tetap diperiksa dalam bentuk mentah dan ter-escape.
- L01: kontrol positif memeriksa ID, FK dan identitas uploader/student pada API, serta model/koleksi/relasi dan marker resource sendiri pada view web. Respons sukses juga diperiksa terhadap marker resource target asing.
- L02: delapan tes guest web memakai ID fixture aktual yang terlebih dahulu dibuktikan ada, bukan hardcoded 1.
- L03: bukti disimpan dalam folder unik per run dengan manifest command/exit/waktu dan hash source serta artefak; bukti historis sebelumnya tetap utuh.

[Bukti kontrol M01](evidence/runs/20261011-194601459725-new-4d0666db/new.xml) berada pada Unit JsonPrivacyAssertionTest (8 kasus / 17 assertion). Kontrol ini membuktikan helper menolak path ter-escape, nested value, pesan, key, Unicode, quotes, dan scalar JSON yang bocor; ini bukan mock request aplikasi atau baris skenario IDOR tambahan. Run awal yang gagal karena ekspektasi tes baru keliru tetap dicatat dalam test-results, kemudian dikoreksi sesuai kontrak asli.

M02 untuk database/seeder demo kini **CLOSED / PASS**, dengan [bukti persiapan](evidence/demo-preparation-20261011.md) dan verifikasi ID/relasi/berkas secara read-only. Keputusan akhir audit **PASS** untuk verifikasi otomatis, mitigasi IDOR, regresi, dan kesiapan infrastruktur demo. ID demo riil ada di [panduan UTS](uat-demo-script.md). ID factory tes otomatis tidak disamakan dengan ID database demo. Presentasi interaktif tetap **READY FOR UTS DEMO / PENDING PRESENTATION**, tanpa klaim sudah dilaksanakan atau direkam.
